# TAREA: Mockups de diseño para la web NEERLANDESA (nl/) — Peptidux NL

Genera 4 mockups de concepto de diseño para una tienda de research peptides en neerlandés. El diseño debe ser COMPLETAMENTE DIFERENTE al Dark Lab de la web EN (fondo oscuro #081014, cyan). Este es un diseño nuevo.

## Contexto del negocio
- Tienda de péptidos de investigación (research peptides) para el mercado neerlandés
- Público: investigadores, biohackers, entusiastas de fitness
- Productos: semaglutide, tirzepatide, BPC-157, NAD+, HGH, etc.
- Pago crypto (USDT, BTC, LTC, XMR)
- Debe verse profesional, confiable, NO como tienda de esteroides, NO como scam

## Los 4 conceptos (uno por imagen)

### Concepto A: "Dutch Clean Lab" — minimalista claro
- Fondo blanco/off-white (#FAFAF8), texto gris oscuro (#1A1A1A)
- Acento: verde menta (#10B981) o azul petróleo (#0F766E)
- Tipografía: sans-serif geométrica limpia (estilo Inter/Manrope pero no esas — usa algo como "Sora" o "Outfit")
- Estilo: laboratorio farmacéutico holandés, limpio, mucho espacio blanco, tarjetas con bordes sutiles
- Hero: producto sobre fondo claro con sombra suave

### Concepto B: "Amsterdam Tech" — dark tech con neón
- Fondo gris grafito (#0D0F12), texto blanco
- Acento: naranja neón (#FF6B2C) o lima (#A3E635)
- Tipografía: display bold condensada + mono para datos
- Estilo: startup tech moderna, gradientes sutiles, glassmorphism en tarjetas
- Hero: grid de datos/estadísticas con glow

### Concepto C: "Nordic Pharma" — escandinavo frío
- Fondo azul grisáceo muy claro (#F0F4F8), texto azul oscuro (#0B2545)
- Acento: azul hielo (#4CC9F0) o dorado suave (#C9A227)
- Tipografía: serif elegante para títulos + sans para body
- Estilo: farmacia premium escandinava, sobria, confiable, tipografía editorial
- Hero: vial sobre fondo azul hielo con luz suave

### Concepto D: "Biohacker Grid" — técnico oscuro
- Fondo negro azulado (#05080C), texto verde pálido (#C8F7C5)
- Acento: verde terminal (#22C55E) + ámbar para warnings
- Tipografía: mono en todo (estilo terminal de laboratorio)
- Estilo: dashboard de laboratorio, grids visibles, datos técnicos prominentes, scanlines sutiles
- Hero: panel de "datos de lote" estilo terminal
